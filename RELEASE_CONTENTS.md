# Release contents

Version: `0.1.0-preview`

## Public files

- project overview, scope, citation, license, and release policy;
- `orderfuse_pam.metrics` evaluation utilities;
- synthetic demonstration;
- unit tests;
- automated public-release audit and checksum manifest.

## Deliberately absent

- source or derived photoacoustic data;
- model weights, logits, predictions, and result tables;
- model, trainer, data-loader, preprocessing, and inference source code;
- local or remote machine paths;
- experiment identifiers, private manifests, and credentials;
- the submitted manuscript PDF.

This split is intentional. The preview is useful for checking metric definitions but cannot regenerate manuscript results.
